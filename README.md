# 哈苏照片管家 · Hasselblad Photo Steward

给在 Mac 上挑照片、在手机 Phocus 里加水印分享的人。插上相机或读卡器，在本地审片台并排比较连拍，把喜欢的照片加进一张带缩略图和原文件名的手机选片单。

## 用 Codex 打开

在 Mac 的 Codex 桌面 App 里打开一个空的本地工作文件夹，把下面这句话发给它：

> 帮我下载 https://github.com/wenz-ai/hasselblad-photo-steward 的公开源码到当前文件夹，读项目里的 AGENTS.md，然后用 /bin/sh bootstrap.sh --no-open 启动照片管家。把实际的本地审片地址打开给我。相机已经连上，我自己确认删除。

也可以在这句话末尾给出照片文件夹。下载源码可以直接使用 [GitHub ZIP](https://github.com/wenz-ai/hasselblad-photo-steward/archive/refs/heads/main.zip)。第一次运行需要联网下载运行环境，并允许访问自己选的照片目录。启动器会校验下载的 uv 引导程序，用锁文件安装私有 Python 环境。用户无需手装 Git、Homebrew、Python、OpenCV 或 Phocus，也无需配置 OpenAI API Key。

本版面向 macOS，已在 Apple Silicon Mac 上验证。需要本地执行权限，运行环境按 macOS 14 或更新版本准备；Intel Mac 尚未实机测试。网页只监听本机回环地址。Phocus Mobile 是导出哈苏水印时的可选后续步骤。

## 让 AI 看图

进入「AI 选片」即可先试一组或评审整库。登录方式默认 ChatGPT 订阅，可在右上角「设置」更改；选择保存在本机，所有片库共用。相似选片可直接评当前对照的两张或整组；单张照片的评片卡也可以单独送评。照片管家调用本机官方 Codex CLI 的图片输入；支持使用订阅额度的 ChatGPT 账号即可工作。它会检查登录方式，不会自动切换到按量计费。若想用 API Key，在官方 CLI 中完成 Key 登录，然后在设置中选相应模式。[Codex 登录方式](https://developers.openai.com/codex/auth) · [非交互运行](https://developers.openai.com/codex/noninteractive)

确认框会列出本次张数、批次、缓存命中数、文件名和选片策略。确认后，最长边 1200 像素、去掉 EXIF 的 JPEG 预览会通过 Codex 发往 OpenAI。推理消耗对应账号的额度。默认采用 Codex 配置中的模型；也可以在启动时通过 `PHOTO_STEWARD_MODEL` 指定该账号有权限的视觉模型。找不到 CLI 时可从桌面 App 启用它或安装官方 Codex CLI。

每批最多六张。已有相似组一起发送，独立照片按日期和拍摄顺序分批，大组拆批。AI 能发现同批中初筛漏掉的相似照片；跨批画面没有逐对做视觉比对。结果分为精选、保留、相似备选、疑似废片和需复核。可以按建议筛选、按分享分排序，或导出单独的「AI 精选单」。逐批完成即保存；可在本批后暂停，重开后重复选择相同范围会复用已完成的批次。浏览器关闭后不会提交下一批。

### 在照片旁读评片卡

- **画面证据**。展示当次模型写下的具体观察、同批对照片、判断限制，以及另一种合理取舍。新版 AI 点评按曝光、对焦、构图、审美各 25 分给出可见证据，再合成分享推荐分。旧记录保留原评分口径。模型评语是可质疑的主观观察。
- **实际输入与输出**。每次成功调用在本机保存策略版本、时间、模型标识、登录方式、送评顺序、预览尺寸及 SHA-256、当次完整用户提示词和模型原始结构化评语。再次点击只读历史，不会重新调用模型。缩略图展示该片库内的照片，指纹对应实际发送的 JPEG。
- **本地技术分**。同一页可查看独立的像素测量分项和公式，了解逆光、大片留白或复杂背景怎样影响初筛。技术分和 AI 分享分各自保留。
- **后期取舍**。分开说明画面可以怎样修、值不值得投入、裁切能改善什么及会牺牲什么。若 RAW 余量未确认，或裁切有望改善，模型给出的疑似废片会留待复核。评片不执行任何后期操作。
- **操作结果**。AI 评审产生建议并可导出名单。只有用户在移除清单中最终确认才会移动文件。

## 怎么挑

1. **分享精选**先展示相机星级、预览技术分靠前的候选。点星星增减入选照片。
2. **相似选片**把两张照片放在同样大小的画框中。左图可固定，更换参照时点「右图设为参照」。底片按拍摄顺序排列，← → 切换右图，Shift + ← → 切换组。「同步放大 2×」可移动或轻触查看两张预览的相同相对位置。选「只选左图」「两张都选」或「只选右图」，会替换本组的分享精选并更新手机选片单。其他组和相机原件保留。**淘汰候选**优先展示画质疑点，再按技术分从低到高排。
3. **显示手机选片单**会在 Finder 定位到独立 HTML。可自行传到手机，对照缩略图、日期和原文件名，在 Phocus Mobile 选择相机原片。网页里的预览最长边为 1440 像素。
4. **待移除**只做标记。进入**移除清单**后会列出张数、文件数、体积及各自的格式，最终确认才将对应原件移入来源磁盘的废纸篓。同目录、同名的 3FR 和 HEIC/JPG 一起处理。

支持带兼容内嵌 JPEG 预览的 3FR，以及 JPG/JPEG、HEIC/HEIF。X2D 100C 已实机验证，其他哈苏机型的 RAW 兼容性需要按样片验证。无法解码的拍摄组会跳过，并在该片库的 `skipped.json` 记录原因。本地初筛和预览生成在本机完成。启用「AI 选片」并确认发送范围后，Codex 才会收到对应预览。

## 推荐是怎么来的

- **相似度**看十分钟内的构图、明暗分布和颜色直方图。对三分钟内发生轻微位移的画面，还会用 SIFT 特征点验证构图关系。
- **技术分**取 36 个区域的局部细节、亮度分布和高低光截断比例。先按相机已有星级、再按技术分排序。相似组默认推荐一张，五张及以上的组推荐两张。
- **查看依据**：候选卡片会显示对照片的文件名、间隔和直接匹配结果。展开「技术分怎么算」可查看该照片的实际分项。基础分为 51；局部纹理项为 10 × log₂(max(1, 纹理强度) / 4)；明暗项为 8 × min(1, 亮度跨度 / 150)；高低光扣分为 35 × max(0, 截断像素比例 − 0.06)。总分限制在 12–98 后取整。纹理来自最长边 560 像素的预览，无法定位主体焦点。
- **分享精选**从组内推荐和独立画面中取约总张数的 7%，最多 40 张。逆光、剪影、浅景深可能被低估，表情与动作由你判断。所有建议都可以复核。

## 再次使用

在项目目录下执行，也可以把这些话直接交给 Codex。

```sh
# 自动寻找相机卷的 DCIM 文件夹
/bin/sh bootstrap.sh

# 指定来源，保留本机目录里的原照片
/bin/sh bootstrap.sh --source "$HOME/Pictures/待选照片"

# 相机离线时也可以用缓存预览继续选，上次的星标和待移除清单会保留
/bin/sh bootstrap.sh --last

# 新增照片后创建新一轮选片。旧片库仍单独保存
/bin/sh bootstrap.sh --source "$HOME/Pictures/待选照片" --rescan
```

索引、预览、SQLite 选片记录和手机选片单位于 `~/Library/Application Support/PhotoSteward/libraries/`，运行环境位于同级的 `runtime/`。终端按 Ctrl+C 停止服务。首次安装完成后可以离线继续选片。
